# MovieLens Dataset Analysis

## Description
This project contains an analysis and visualization of the MovieLens dataset using Python. The analysis is performed in a Jupyter notebook (`IDMB.ipynb`) and covers data loading, cleaning, descriptive statistics, filtering, grouping, merging, and visualization.

## Dataset
The dataset used is the MovieLens dataset, which is maintained by the GroupLens Research group at the University of Minnesota. The dataset includes user ratings, movie tags, and movie information.

## Libraries Used
- pandas
- matplotlib

## Summary of Analysis
- Loading CSV files containing ratings, tags, and movies data.
- Data cleaning to handle missing values.
- Descriptive statistics and data exploration.
- Filtering and grouping data for insights.
- Merging datasets for combined analysis.
- Visualizing data distributions and relationships.

## How to Run
1. Install the required Python packages:
   ```
   pip install -r requirements.txt
   ```
2. Open the `IDMB.ipynb` notebook in Jupyter Notebook or JupyterLab.
3. Run the notebook cells sequentially to reproduce the analysis.

## Notes
- The dataset CSV files should be placed in the appropriate directory as referenced in the notebook.
- Adjust file paths in the notebook if necessary to match your local environment.
